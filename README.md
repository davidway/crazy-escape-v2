本仓库给 Claude / 协作者读代码用，不是上架包。

- 引擎：**Cocos Creator 2.4.13**
- 大厅换皮逻辑：`assets/scripts/LobbyArcade.js`
- 主角 Spine：`assets/actors/heros/zj1/`（默认皮 `playerSkinConf` id=1，动画名 Walk/Standby/Attack/Death）
